================================================================================
COMMON QUESTIONS & ANSWERS
================================================================================

Q: Why React instead of Angular?
A: Larger ecosystem, better performance, easier learning curve, industry standard

Q: Why TanStack Query instead of Redux?
A: Designed for server state, automatic caching, less boilerplate, perfect for API-heavy apps

Q: How does debouncing work?
A: Uses useRef + useEffect. Waits 300ms after user stops typing before making API call

Q: How is security implemented?
A: Three layers - Route level (ProtectedRoute), Component level (conditional rendering), API level (backend validation)

Q: What prevents duplicate submissions?
A: Idempotency keys - unique key for each POST request, backend checks if already processed

Q: How does token refresh work?
A: Axios interceptor catches 401 errors, tries to refresh token, retries original request

Q: What's the pagination strategy?
A: Server-side pagination - only requested page data is fetched, not entire dataset

Q: How are passwords secured?
A: BCrypt hashing with strength 12, never stored in plain text

Q: What happens after 5 failed logins?
A: Account automatically locks, admin/dealer can unlock via UI

Q: How are audit fields populated?
A: Spring Data JPA @EntityListeners with AuditorAwareImpl, automatically fills createdBy/updatedBy
